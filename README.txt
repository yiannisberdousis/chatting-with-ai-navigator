Chatting with AI — Teacher Navigator FINAL: Common Materials First / No Walkthrough Files

This package preserves the approved project structure and educational content while simplifying the teacher-facing resource flow.

Release changes in this version:
- Common materials are presented before route selection, so teachers download the Lite Teacher Guide and other route-neutral resources only once.
- After a route is selected, the Navigator shows only materials specific to that route.
- Standalone Teacher Walkthrough files have been removed.
- A content audit was completed against each Lite Teacher Guide. Only genuinely unique, useful teacher support from the walkthroughs was retained, primarily concise teacher language/prompts and two practical contingencies.
- Existing learning sequence, student outputs, evidence logic, GenAI prompts, safeguarding, route-specific implementation resources and other educational content remain unchanged.

Open index.html after extracting the ZIP and keep the resources folder beside it.
