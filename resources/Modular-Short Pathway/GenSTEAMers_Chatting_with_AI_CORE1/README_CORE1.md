# Chatting with AI — CORE 1 Release

## CORE 1: Exploring Existing Chatbots

**Duration:** approximately 45 minutes  
**Pathway:** Modular / Short Pathway  
**Student role:** critical evaluator  
**Optional GenAI role:** bias critic / reflection support

This release-ready package supports CORE 1 of the modular pathway. Students evaluate chatbot responses before designing their own chatbot in CORE 2. They identify evidence, assumptions, possible bias, safety concerns, accuracy issues and limitations, then write one **“A good chatbot should...”** principle that becomes a design requirement for CORE 2 and a test criterion in CORE 3.

## 45-minute classroom logic

1. Choose **one route** only.
2. Evaluate **two chatbot responses**.
3. Select **one response for closer checking**.
4. Support the judgement with evidence.
5. Identify assumptions, bias, missing information, safety, accuracy or limitations.
6. Write one **“A good chatbot should...”** principle for CORE 2.

If time is tight, keep the second response evaluation brief and protect the closer check and final CORE 2 principle.

## Minimum materials for one lesson

Use:

- `ChattingwithAI_TeacherGuide_Modular_CORE1.docx` or the shorter `01_Teacher_Walkthrough_45min.docx`;
- pages 1–4 of `03_CORE1_Student_Worksheet.docx`;
- one route-specific file: Route A, Route B or Route C.

Optional:

- page 5 of the Student Worksheet, only when GenAI-supported reflection is used;
- `00_Teacher_Route_Selection_Sheet.docx`;
- `02_Whole_Class_Debrief_Board.docx`;
- `04_Chatbot_Observation_Checklist.docx`;
- `08_GenAI_Supported_Evaluation_Prompts.docx`.

## Printing and distribution

- **Student Worksheet:** print pages 1–4 for every group. Print page 5 only when using the optional GenAI Reflection Trace.
- **Route A:** page 1 is the student prompt set; page 2 is teacher-only guidance.
- **Route B:** pages 1–3 contain student examples; page 4 is the teacher-only challenge map.
- **Route C:** page 1 contains setup instructions; give each group only its assigned bot-card page from pages 2–6. Page 7 is teacher-only guidance.
- **Observation Checklist:** one copy per group is sufficient when used.

## Route summary

### Route A — Live Chatbot
Use when students may interact with a school-approved chatbot. Live outputs may vary. Use safe prompts and no personal information. Assign different themes across groups where possible.

### Route B — Provided Examples
Recommended default for first implementation, limited tool access or strict timing. The examples are intentionally designed to surface clarity, accuracy, assumptions, bias, safety and limitations.

### Route C — Human-Bot Role-Play
Use for a no-tech implementation or to make simple rule-based chatbot logic visible. Use groups of at least three. Evaluate the rules and response pattern, not the student playing the bot.

## Student outputs

Each group produces:

1. a completed required part of the CORE 1 Student Worksheet;
2. a quick evaluation of two responses;
3. one selected response for closer checking;
4. evidence supporting the group judgement;
5. one note about assumptions, bias, missing perspectives, safety, accuracy or limitations;
6. one **“A good chatbot should...”** principle for CORE 2.

## Core message

You do not need to use every file. Choose one route, evaluate two responses, and protect the final bridge to CORE 2.
