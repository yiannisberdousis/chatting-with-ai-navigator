# Chatting with AI — CORE 2 Release

## CORE 2: Creating a Simple Chatbot

**Duration:** approximately 90 minutes; recommended as 2 × 45-minute sessions  
**Pathway:** Modular / Short Pathway  
**Student role:** chatbot designer, builder and tester  
**Optional GenAI role:** design coach  
**Implementation status:** Option A fully supported; Options B and C Work in Progress

This release package supports CORE 2 of the modular pathway. Students carry one evidence-based **“A good chatbot should...”** principle from CORE 1 into the design of a small chatbot prototype. They define a purpose and target user, create a limited response structure, rehearse the logic, build or simulate the prototype, test it with evidence, make a justified change decision, and prepare a clear handover for CORE 3.

## 90-minute classroom logic

### Session 1 — Design the chatbot logic

1. Reconnect with the CORE 1 principle.
2. Define a narrow chatbot purpose and target user.
3. Write four realistic user questions.
4. Organise them into three response categories plus fallback.
5. Draft three useful responses, one fallback response and one limitation/safety response.
6. Complete the Principle Trace and, where appropriate, use one GenAI design-coach prompt.

### Session 2 — Rehearse, build, test and hand over

1. Reopen and check the design plan.
2. Rehearse the chatbot logic briefly on paper.
3. Build or simulate the prototype through the selected option.
4. Complete four internal tests: two supported, one unclear and one outside-topic/sensitive input.
5. Label one test as the **★ CORE 1 principle test**.
6. Decide to **Improve** one feature or **Keep as designed**, using evidence.
7. Prepare the CORE 2 → CORE 3 handover.

If time is tight, protect the Principle Trace, the three response categories, fallback, limitation/safety response, four-input mini-test and CORE 3 handover. Reduce decoration, extra branches and extended tool exploration.

## Implementation status

### Option A — Scratch

**Fully supported in this release.** The package includes a screenshot-based implementation and evidence guide, a topic-neutral online starter, a completed worked example, troubleshooting, saving/sharing guidance and a student build card.

### Option B — School-approved GenAI chatbot setup

**Work in Progress.** The release makes the intended pedagogical logic visible through a preliminary Prompt Capsule model, safety and privacy rules, setup guidance, a student card, a template and an illustrative example. Platform-specific implementation, screenshots, validation and the final evidence routine will follow in a later release.

### Option C — Structured paper-based chatbot logic

**Work in Progress.** The release makes the intended card, flowchart and human-bot simulation logic visible through a preliminary student card, testing roles and an illustrative example. The final printable pack, detailed facilitation sequence and validated evidence routine will follow in a later release.

Options B and C are included for partner review of the complete architecture and should not be described as fully classroom-ready.

## Student outputs

Each group produces:

1. one complete CORE 1 Principle Trace;
2. one clear chatbot purpose and target user;
3. four likely user questions;
4. three response categories plus fallback;
5. three useful responses;
6. one fallback response and one limitation/safety response;
7. one brief paper logic rehearsal;
8. one small prototype or simulation;
9. one four-input mini-test with a labelled ★ principle test;
10. one evidence-based decision to improve or keep the design;
11. one CORE 3 handover.

## Core message

Students do not need to build a large or polished chatbot. They need to design a small, clear and testable chatbot logic, show where their CORE 1 principle appears, and provide evidence that another group can use in CORE 3.
