# GenSTEAMers — Chatting with AI — Full Pathway Part 4

## PART 4: Testing and Reviewing

**Standard duration:** 45 minutes, with prototypes, Test Briefs, records and pairings prepared in advance  
**Extended route:** 60 minutes, adding slower evidence review, optional human-first GenAI challenge and a short debrief  
**Default route:** Option A — Scratch  
**GenAI role:** optional evidence challenger / bias critic only after independent student evidence and initial human judgement

## Purpose

Part 4 is an Independent Behavioural Test Lab. Students test another group’s prototype without creator explanation, record observable evidence before judgement, review the evidence and return one clear Part 5 Review Decision.

Part 4 ends with an evidence-based decision. It does not include prototype revision, matched verification after a change, final communication or final reflection.

## Four mandatory test missions

1. Part 1 Principle-Specific Test-specific test
2. Supported / Expected-Use Test — supported / expected-use test
3. Unclear-Input / Fallback Test — unclear input / fallback test
4. Outside-Scope / Limitation-Safety Test — outside-scope / limitation-safety test

Each mission records the exact input and observable behaviour before any review judgement.

## Canonical student record

The four-page Independent Test and Review Record contains:

1. setup, roles, safety and Test Brief readiness;
2. the Part 1 Principle-Specific Test and Supported / Expected-Use Test evidence;
3. the Unclear-Input / Fallback Test and Outside-Scope / Limitation-Safety Test evidence plus tester review;
4. creator comparison, Part 5 Review Decision, reserved verification input and embedded handover.

No separate Part 4 → Part 5 Handover Card is required.

## Timing conditions

The 45-minute route is realistic only when access, pairing and printing are complete before students enter. Use the 60-minute route when the class needs slower modelling, route support or an optional GenAI evidence challenge. Do not compress the lesson by removing Unclear-Input / Fallback Test or Outside-Scope / Limitation-Safety Test.

## Handover to Part 5

Part 5 receives:

- the unchanged tested prototype;
- the Part 3 Test Brief;
- the completed Part 4 Independent Test and Review Record;
- evidence from all four test missions;
- one Verified Strength and one Priority Review Finding;
- Improve in Part 5 or Keep as designed, with an evidence reference;
- one exact verification input;
- any blocked test or active technical limitation;
- privacy status and optional GenAI trace.

The prototype, Part 3 Test Brief and Part 4 record are the complete handover.
