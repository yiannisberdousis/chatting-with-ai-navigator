# Chatting with AI — Full Pathway Part 2

## Part 2: Designing Chatbot Logic

**Recommended duration:** 2 × 30 minutes  
**Compact route:** 1 × 45 minutes  
**Pathway position:** Part 2 of 5  
**Student role:** chatbot logic designer  
**Optional GenAI role:** design coach after the first student draft

Part 2 continues the sequential Full Pathway:

**Part 1 evidence and principle → Part 2 chatbot logic blueprint → Part 3 prototype construction → Part 4 testing and reviewing → Part 5 refinement and communication**

Students retrieve the evidence-based **“A good chatbot should...”** principle from Part 1 and convert it into a specific design requirement. They then define a safe purpose and target user, organise four likely questions into three response categories, write three model responses, and design distinct fallback and limitation/safety behaviour.

Part 2 is design-focused. Students do **not** open a build tool, write Scratch scripts, create a Prompt Capsule, or test a working prototype.

## Teacher Guide first

`ChattingwithAI_TeacherGuide_FULL_PART2.docx` is the main implementation document. All other files support the Teacher Guide and should be used only when needed.

The shorter Teacher Walkthrough is an optional in-class reference. It does not replace the Teacher Guide.

## Recommended 2 × 30-minute route

### Session 1 — Carry evidence forward and define

1. Retrieve the Part 1 principle and evidence behind the principle.
2. Convert the principle into one specific design requirement and planned visible feature.
3. Define the chatbot purpose, target user, and scope.
4. Write four realistic likely user questions.
5. Complete the Session 1 checkpoint and save the worksheet.

### Session 2 — Organise and complete the logic

1. Confirm the Session 1 design.
2. Organise the four questions into three response categories.
3. Write one model response per category.
4. Write a fallback and a distinct limitation/safety response.
5. Complete a short tool-free design walkthrough.
6. Complete the embedded Part 2 → Part 3 Build Brief.

## 45-minute compact route

The compact route protects the same minimum logic but requires:

- the same groups from Part 1 where possible;
- immediate access to the Part 1 record;
- pre-approved or rapidly approved safe topics;
- one- or two-sentence responses;
- no optional GenAI coaching during the core lesson;
- no whole-class presentation, interface design, or alternative prototype exploration.

If one precise issue remains, the group marks **Revise first** and repairs that item at the opening of Part 3 before using a build tool.

## Minimum materials for one implementation

Use:

- the **Part 2 Teacher Guide** as the main implementation document;
- pages 1–4 of `01_PART2_Chatbot_Logic_Design_Worksheet.docx`, one copy per group;
- each group’s completed Part 1 principle and evidence trace.

Optional:

- `00_Teacher_Walkthrough_PART2.docx` as an in-class quick reference;
- `02_Safe_Topic_and_Scope_Card.docx` only when groups need topic support;
- `03_GenAI_Design_Coach_Prompts.docx` and page 5 of the Student Worksheet only when GenAI use is approved and time allows.

## Printing and distribution

- **Student Worksheet:** print pages 1–4 for every group. Print page 5 only when using optional GenAI design coaching.
- **Safe Topic and Scope Card:** display it or keep a few shared copies; do not automatically print one per group.
- **GenAI Design Coach Prompts:** one shared copy or projected version is sufficient. Students use one prompt only.
- **Teacher Walkthrough:** optional teacher copy; students do not need it.

## Part 1 → Part 2 continuity

Part 2 must begin with the actual Part 1 principle and evidence trace. The principle is converted into:

1. a specific design requirement;
2. a planned visible feature; and
3. a future test idea with expected behaviour.

The future test is planned in Part 2, implemented through the Part 3 prototype, and used as evidence during Part 4 testing.

## Part 2 → Part 3 continuity

No separate handover card is required. Pages 1–4 of the Student Worksheet are the canonical **Chatbot Logic Blueprint** and the embedded **Part 3 Build Brief**.

Before Part 3, collect, photograph, or digitally save each group’s worksheet. The prototype should be built from the agreed logic. Students must not invent new categories or replace agreed responses during Part 3. Only the single **Revise first** repair recorded before the build environment opens may change the approved blueprint. Evidence-based design improvement belongs to Part 5.

## Core message

Read the Teacher Guide, protect the principle-to-requirement bridge, keep the topic narrow, complete one canonical logic blueprint, and stop before construction begins.
